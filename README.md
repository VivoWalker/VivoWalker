### 精选项目

#### [ACAHKU Phigros Broadcast](https://github.com/VivoWalker/ACAHKU-Phigros-Competition-2026)

给 Phigros 比赛用的本地转播系统：OBS 叠层、赛事控制、独立记分面板，以及电脑与 iPad 之间的实时同步。

`JavaScript` `Node.js` `Express` `Socket.IO` `OBS`

#### [X 帖子截图](https://github.com/VivoWalker/x-post-screenshot)

选中帖子，截取完整内容并复制到剪贴板。支持长帖、多图与回复对话；Chrome 版还支持视频帖录制。

`JavaScript` `Chrome` `Firefox` `Manifest V3`

#### [GPU × Crypto Analysis](https://github.com/VivoWalker/COMP2501-GPU-Crypto-Analysis)

从数据出发，研究加密货币价格与 NVIDIA GPU 二手市场价格的关系，覆盖 2020–2022 年的挖矿热潮与回落。

`Python` `R` `Data visualization`
